## Mandatory learned-CFM definition and budgets
Minimal independently written vector field: three hidden layers of width 128 with time embedding, noisy continuous target and context values/mask inputs. Straight linear conditional flow-matching path from iid Gaussian source to dequantized map target. For binary b, target continuous coordinate (2*b-1)+Uniform(-0.1,0.1), so threshold at zero recovers b. For unobserved cells learn/sample velocity; observed cells remain the legitimate recorded binary values. Threshold missing outputs at zero to obtain binary full maps. Never nearest-catalog-project decoded maps: outside-catalog mass is real model error, not discarded. Fixed known boundary cells are conditioned in both arms.

Proposed identical training schedule: Adam, batch 128, 2,000 updates, same learning rate chosen once on development and frozen; no method-specific hyperparameter search. Equal examples/updates/capacity is the primary budget match, not a guarantee of equal wall time. Record wall time and stop/go using the compute envelope. At evaluation K=128 independent Gaussian source draws per record; fixed-step Euler with 32 field evaluations, same across arms. Any higher-step diagnostic is labeled secondary, never replaces the primary. No additional neural baseline is necessary to identify the within-CFM policy intervention; conclusions cannot establish FM specificity.
