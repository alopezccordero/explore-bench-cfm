## Inputs, population and data
Input: a manifest with map-family identifier, 16x16 binary true map, discrete prior over at most 16 feasible world hypotheses, initial pose/goal, four-neighbor motion, sensor range (one or three cells), regime parameters and random seed. Start and goal are valid free cells. Generate corridor/doorway families with either a free fallback route or no route; do not discard impossible goals after seeing a policy outcome. The full manifest defines true P; every method is evaluated on worlds drawn from that same P.

Minimum sensor model: noiseless occupancy of cells within Manhattan radius one or three, with known pose and no additional occlusion model; this deliberately simplified simulator is not lidar realism. Prior is uniform over the family's at most 16 declared world hypotheses, conditioned by eliminating hypotheses inconsistent with observed cells. For planning use edge cost 1 + 4p(destination occupied). For accumulation use symmetric speculative log-odds increments +/-w from each sample's occupied/free label, averaged over K before adding once per update; start at zero speculative log odds and clamp to +/-L. For replacement use current sample-frequency p on unobserved cells. To match the 12-configuration tuning allowance, A uses h in {0,1,2,4,8,16,32,64,128,256,512,1024}; B uses h in {0,4,16}, w in {0.2,0.8}, L in {1,3}. This deliberately finite tuning envelope is part of the estimand, not a proof against all possible accumulators. Sensor-observed cells use sensor-only values in every arm; safeguards invalidate any route containing an observed occupied cell.

Initial design: 20 development families, 20 validation families and 40 untouched test families, each with five episode seeds (0–4); counts are feasibility targets, not power calculations. Family/layout templates, not adjacent timesteps, determine splits. Prevent equivalent rotated/reflected layouts from crossing splits using a canonical family key. No learned training set in minimum study. New synthetic artifacts have no third-party data access dependency; author-selected release license is pending. No SceneSense data/weights availability is assumed.

Prespecified strata cross low/high completion volatility, sensor range, and low/high probability that a previously inferred passage is contradicted on observation. All strata have common fixed weights. Static true worlds only. Construct completion volatility by holding a valid posterior sample for one versus four decision steps between recomputations when observations are unchanged; any new genuine observation invalidates incompatible samples immediately in every arm. This changes temporal correlation, not the underlying sensor information. Sample K=8 hypotheses from the exact finite-world posterior at each update with paired uniform draws. K and inference access are equal across arms; oracle true world is never exposed to policy. Any distorted completion distribution is a separately labeled sensitivity analysis, not posterior calibration evidence.

## Systems, fairness and intervention isolation
Maintain sensor-only log odds separately in every method. Genuine measurements update those beliefs once using identical likelihoods. Any newly sensed occupied cell imposes the same immediate movement veto. Prediction values never overwrite observed sensor-only values.

Representation A: current posterior sample-frequency completion on unobserved cells replaces the previous speculative layer; it does not multiply repeated predictions as likelihoods. Representation B: predicted occupied/free increments update a bounded speculative log-odds layer on unobserved cells; sensor-overwrite removes that speculative layer on first genuine observation. Include a retained-layer diagnostic but do not call it the deployed SceneSense default.

Cross A/B with route hysteresis disabled/enabled. Planner is identical risk-weighted shortest-path search with fixed edge cost 1+4p(destination occupied), as specified above; only route hysteresis, speculative weight and clamp are validation-tuned in the declared grids. Enabled hysteresis retains the previous route unless a new feasible route improves estimated remaining cost by more than h; h is tuned on validation. Newly observed obstacles invalidate the route immediately regardless of h. Re-score old and new routes under current map; no privileged saved oracle scores. Deterministic lexicographic ties. Safe no-path behavior is sense-in-place until budget exhaustion, not zero-cost termination.

Equal validation budget: at most 12 prespecified configurations per representation, same total tuning CPU time. Tune h, prediction increment/weight and clamp bounds jointly from documented grids on validation only; record all candidates. Headline compares A with tuned hysteresis to best safeguarded B configuration (B may also use hysteresis). Report all factorial cells to avoid crediting planner memory to representation. Include sensor-only/no-completion baseline and unbounded accumulation only as diagnostics. No claim these are exact SceneSense deployment settings.

Each decision has the same planned 100 ms wall-time deadline on a recorded CPU, same K, same replanning frequency and memory envelope. Charge posterior sampling, fusion, route scoring and hysteresis against it. On deadline, follow only a still-valid previous action; if none exists use sense-in-place. Repeated deadlines consume actions and can reach cap. Instrumentation reports timing, not fictional runtime equality. Pre-generated random tapes are coupling aids; sampling cost is measured or uniformly charged rather than silently free for one system.

## Output and primary scoring
Output one row per episode/method with goal status, total cost, collision attempts, route changes, post-contradiction cost, wall-time/deadlines, seed/family and failure reason. Primary is mean capped navigation cost as exactly defined in metric.json: movement/sensing 1, blocked attempt 11, failed episode total 512. Impossible-goal episodes remain, with the same cap for every arm. Numerical errors, invalid actions and method-specific aborts are failures, never deleted. Independent units are families; episodes are nested paired replicates. Average within family then across fixed-weight strata. Report paired family-cluster bootstrap intervals and sensitivity to five evaluator seeds; no significance-to-equivalence inference. Tolerance +/-5 is an assumed practical interval awaiting owner acceptance. Secondary stability/calibration measures cannot replace primary cost.

## Tests to build, not tests already run
1. Fully observed free grid: all representations agree and reach goal by the known shortest path with zero collision attempts.

5. Zero hysteresis reproduces base planner; sufficiently large h retains a valid old route but cannot retain a physically invalid one.

7. Shared seed/manifest produces identical world/sensor tapes across policies; different routes may legitimately yield different observations from the same world.
8. Failure/deadline paths retain rows and score cap consistently; no route yields infinite loops beyond budget.
9. Exact finite-world posterior normalizes, respects sensor support and never reads hidden true-world labels. Zero-support observations trigger a common declared robust fallback to sensor-only planning and are logged.
10. Frozen split canonicalization catches related layouts and post hoc exclusions.
